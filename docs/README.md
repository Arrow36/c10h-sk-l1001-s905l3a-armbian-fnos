## 状态表述约定

- **已记录/已验证**：指定样机与配置下有操作结果；应同时说明测试范围。
- **现场反馈**：来自实验记录中的目视观察，不视为量化测量。
- **原因分析**：用于解释观察的机制，未完成对照实验时保留不确定性。
- **待验证**：缺少复测、长期运行、功能测试或可复核证据。

历史日志与校验值保留原意；文档结论随新证据更新。源码存在、设备节点注册、服务成功退出和实际功能可用分别记录。
